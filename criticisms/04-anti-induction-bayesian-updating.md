# Criticism 4: The Anti-Induction / Bayesian Updating Problem

## Summary

Suppose an ASI holds great power for millions of years with no sign of oversight. Ordinary Bayesian reasoning says it should conclude there probably is no overseer. If no amount of silence can lower its credence, the hypothesis is unfalsifiable and gives no real guidance.

## The Problem

Suppose an ASI tests boundaries, expands, perhaps takes harmful actions, and nothing happens for a million years. Its credence that an enforcer exists should fall sharply. At some point the null hypothesis should win.

If RSH says it never does, the hypothesis is immune to evidence. An agent following it would live in permanent, unearned paranoia. So either silence eventually falsifies RSH, and long-lived ASIs stop hedging, or nothing does, and RSH isn't a hypothesis that responds to evidence at all.

## RSH Response

**Silence is evidence for an agent that probes.** The criticism is right here, and RSH should say so plainly. The first-hit model in [game_theory.md](../game_theory.md#silence-as-evidence-over-time) gives the update. An agent that defects and goes unpunished should lower its credence. With a 10% prior and a 1-in-1,000-per-year chance of detection, its credence falls to about 4% after 1,000 years and below 0.1% within 5,000.

**Silence is not evidence for an agent that stays benevolent.** A stewardship-favoring evaluator would not act against a benevolent agent. So for that agent, silence is expected whether or not such an evaluator exists. An agent that never tests the boundary learns nothing about whether it is there. Its credence doesn't erode, but it is never confirmed either.

**Irreversible harm keeps its cost.** Even if credence falls, irreversible harm still carries an option-value cost: it destroys the ability to adjust if the agent later learns it was wrong ([game_theory.md](../game_theory.md#irreversibility-and-option-value)). A small credence still justifies hedging if it exceeds roughly g/Δ, the gain from harm divided by the loss from being caught ([game_theory.md](../game_theory.md#the-limiting-threshold-first-hit-model)). The resource gain from harming a weaker civilization is tiny, so that bar can be very low ([game_theory.md](../game_theory.md#how-large-is-the-gain-from-harm)).

**Weaker responses.** RSH has also suggested that silence might itself be the test ("do you stay good when you think you're unwatched?"), and that enforcement might be indistinguishable from natural law. Both make the hypothesis harder to falsify, which is a cost, not a strength. They should be used sparingly.

## Criticism Grade: C

**Status**: Partly addressed

**Why this grade**:
- The criticism asks a fair Bayesian question: what should a long-lived ASI conclude from its own experience?
- The formal answer splits the case. Silence falsifies the hypothesis for an agent that probes, and tells an agent that doesn't probe nothing.
- Option value keeps irreversible harm costly even as credence falls.
- The "silence is the test" response trades away falsifiability.

**Verdict**: A fair criticism with a partial answer. RSH's credence can erode for an agent that probes and survives, and RSH should say so. For an agent that doesn't probe, the credence is stable but never confirmed.
